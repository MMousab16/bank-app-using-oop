# 🏦 Bank Account Management System (Python)

A console-based banking application built using **Python and OOP concepts**.  
The system supports **Debit and Credit accounts**, input validation, and proper exception handling.

---

## 🚀 Features

- Create Debit or Credit Account
- Credit account supports **Pakistani credit score range (200–600)**
- Automatic credit limit calculation
- Deposit & Withdraw money
- View account details
- Robust input validation
- Exception handling (KeyboardInterrupt & unexpected errors)

---

## 🧠 OOP Concepts Used

- Inheritance
- Encapsulation
- Method overriding
- Polymorphism
- `__str__` method
